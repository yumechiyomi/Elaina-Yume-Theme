> 🌙 *Elaina Fuwari — soft, quiet, and dreamy,  
> like a gentle journey through a pastel sky.*

**Elaina Fuwari** is a soft, anime-inspired Jekyll theme focused on calm visuals,
gentle motion, and a peaceful reading experience.

Inspired by *Elaina – The Wandering Witch*, this theme captures the feeling of
traveling slowly through quiet places, observing the world with warmth and curiosity.

---

## ✨ Features
- 🌸 Soft pastel background and gentle color palette
- 🌙 Anime-inspired design (Elaina – The Wandering Witch)
- 🎨 Clean and readable typography
- ✨ Lightweight CSS animations
- 📱 Fully responsive layout
- 🛠 Built on **jekyll-now**

---

## ✨ Animation Showcase
Elaina Fuwari uses subtle animations to enhance atmosphere without distraction.

- 🌸 **Fade-in content**  
  Text and images gently appear when the page loads

- 🌙 **Soft floating elements**  
  Decorative elements move slowly to create a dreamy feeling

- ✨ **Smooth hover transitions**  
  Links and buttons respond softly to user interaction

- 🎐 **Calm scrolling experience**  
  Motion feels slow, light, and relaxing
